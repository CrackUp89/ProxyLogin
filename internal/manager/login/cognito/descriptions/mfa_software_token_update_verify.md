Confirms the new software token (TOTP) MFA setup by verifying the first code produced by the authenticator app.

This endpoint is called after `/v1/mfa/software/update`, once the user has added the TOTP secret to their authenticator app. Submitting a valid code activates the new software token as the user's MFA method, replacing any previously configured one.

Requires a valid auth token via cookie or `Authorization: Bearer` header, plus the update session cookie and CSRF header from `/v1/mfa/software/update/start`.

**Request fields**:
- `code` *(required)* — TOTP code generated by the authenticator app after scanning the secret.

**On success**: the update session is closed and its cookie is cleared.
