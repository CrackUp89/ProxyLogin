Confirms MFA enrolment by verifying the first TOTP code produced by the authenticator app.

This endpoint is called after `/v1/login/mfa/setup`, once the user has added the TOTP secret from the `mfa_token_setup_verify` payload to their authenticator app.

Requires the login session cookie and CSRF header from `/v1/login/start`.

**Request fields**:
- `user` *(required)* — username or email address.
- `code` *(required)* — TOTP code generated by the authenticator app after scanning the secret.

**On success**: MFA is activated for the user. Usually the login flow completes and tokens are delivered using the same mechanism as the `/v1/login` endpoint (cookies or response body, depending on configuration). If Cognito issues another challenge, the response contains a further `next_step` instead.
