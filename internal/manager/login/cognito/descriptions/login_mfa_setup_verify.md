Confirms MFA enrolment by verifying the first TOTP code produced by the authenticator app.

This endpoint is called after `/v1/login/mfa/setup`, once the user has added the TOTP secret from the `mfa_software_token_setup_verify` payload to their authenticator app. Submitting a valid code finalises the enrolment and completes the login flow.

**Request fields**:
- `session` *(required)* — login session key returned by the previous step.
- `user` *(required)* — username or email address.
- `code` *(required)* — TOTP code generated by the authenticator app after scanning the secret.

**On success**: MFA is activated for the user and the login flow completes. Tokens are delivered using the same mechanism as the `/v1/login` endpoint (cookies or response body, depending on configuration).
